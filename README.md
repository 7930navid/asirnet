# 🌐 AsirNet

**AsirNet** is a simple, fast, and user-friendly social posting platform where users can create, edit, and delete posts easily.

This project is built using Node.js and PostgreSQL.

---

## ✨ Features

- 📝 Create new posts  
- 👀 View all posts (latest first)  
- ✏️ Edit your own posts  
- 🗑️ Delete your own posts  
- 👤 Delete all posts of a specific user  
- ⚡ Fast and lightweight backend  
- 🔒 Secure SQL queries (protected against SQL injection)

---

## 🛠️ Tech Stack

### Frontend
- HTML  
- CSS  
- JavaScript  

### Backend
- Node.js  
- Express.js  
- PostgreSQL  

### Security & Tools
- Helmet  
- CORS  
- pg (PostgreSQL client)
